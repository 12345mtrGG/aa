编程打字 · Python / C++

写代码最卡手指的不是字母，是 { } [ ] ( ) ; : < > :: -> && || 这些符号，还有缩进。下面按难度分五关，从符号一直练到完整程序。

英文打字练习

从随机字母到整段文章。这一关练的是「手感」，打好之后编程打字会轻松很多。

拼音中文打字

屏幕给你汉字，你打出它的拼音 —— 比如「中国」就打 zhongguo，然后按空格确认。 这是模拟输入法的练法：所以虚拟键盘照样告诉你该用哪根手指、按错的键也会被统计。 练熟之后，用真实输入法打字会顺手很多。
